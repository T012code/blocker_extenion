# Layo's projects

This repository holds two separate projects.

| Folder | What it is |
| --- | --- |
| [`adblocker/`](adblocker/) | **Layo's Advanced Blocker**: an ad, tracker and malware blocker extension for Chrome and Edge. |
| [`layos-download-manager/`](layos-download-manager/) | **Layó's Download Manager**: a download manager for Windows with multi-connection downloads, browser capture and a video grabber, plus its browser extension. |

Both are developed by [Layó](https://layothedeveloper.com).

Each folder has its own README with build and install steps. Both projects are licensed under the GNU GPL v3 or later (see [LICENSE](LICENSE)).

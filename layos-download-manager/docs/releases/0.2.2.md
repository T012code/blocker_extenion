Layó's Download Manager for Windows: a free download manager that splits each file into many sections, catches downloads from your browser, grabs videos from web pages, and downloads torrents privately.

*Developed by [Layó](https://layothedeveloper.com)*

## Download

| File | What it is |
| --- | --- |
| `LayosDownloadManager_0.2.2_x64-setup.exe` | The installer (Windows 10 and 11, 64-bit). The browser extension is included. |
| `layos-download-manager-chromium-0.2.2.zip` | The extension for Chrome, Edge, Brave, Opera and Vivaldi, to add by hand |
| `layos-download-manager-firefox-0.2.2.zip` | The extension for Firefox, to add by hand |
| `layos-download-manager-chromium-store-0.2.2.zip` | For store submission only (not for installing by hand) |

## Install

1. Run `LayosDownloadManager_0.2.2_x64-setup.exe`. It installs for your user account, with no admin rights needed. Windows may say "Windows protected your PC" because the installer isn't code-signed yet: click **More info → Run anyway**. It installs over earlier versions.
2. In the app, open **Settings → Browser extension** and click your browser.
   - **Chrome, Edge, Brave, Opera:** turn on **Developer mode** on the extensions page the app opens (the app tells you if it's off), then drag the `chromium` folder it shows in File Explorer onto that page.
   - **Firefox:** Firefox opens the extension and asks to add it. Until the extension is signed by Mozilla, release Firefox refuses it; load it for the session from `about:debugging` → This Firefox → Load Temporary Add-on.
3. Click the extension's toolbar button: it should say **Connected**.

If you loaded an earlier version of the extension by hand, remove it first.

## What's new in 0.2.2

- **YouTube video downloads work again.** They failed with "Requested format is not available": recent YouTube needs a JavaScript runtime for yt-dlp, which the installer now includes (Deno). yt-dlp also keeps YouTube's own user agent, and if your browser's cookies make a site offer nothing usable, the app tries again without them.
- **A chosen quality no longer fails** when the site hands out a different set of formats at download time: it falls back to the same height, then the best available.

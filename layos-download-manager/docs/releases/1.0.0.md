Layó's Download Manager for Windows: a free download manager that splits each file into many sections, catches downloads from your browser, saves videos from web pages, and downloads torrents privately.

*Developed by [Layó](https://layothedeveloper.com) · hello@layothedeveloper.com*

## Download

| File | What it is |
| --- | --- |
| `LayosDownloadManager_1.0.0_x64-setup.exe` | The installer (Windows 10 and 11, 64-bit). The browser extension is included. |
| `layos-download-manager-chromium-1.0.0.zip` | The extension for Chrome, Edge, Brave, Opera and Vivaldi, to add by hand |
| `layos-download-manager-firefox-1.0.0.zip` | The extension for Firefox, to add by hand |
| `layos-download-manager-chromium-store-1.0.0.zip` | For store submission only (not for installing by hand) |

## Install

1. Run `LayosDownloadManager_1.0.0_x64-setup.exe`. It installs for your user account, with no admin rights needed. Windows may say "Windows protected your PC" because the installer isn't code-signed yet: click **More info → Run anyway**.
2. In the app, open **Settings → Browser extension** and click your browser.
   - **Chrome, Edge, Brave, Opera:** turn on **Developer mode** on the extensions page the app opens (the app tells you if it's off), then drag the `chromium` folder it shows in File Explorer onto that page.
   - **Firefox:** Firefox opens the extension and asks to add it. Until the extension is signed by Mozilla, release Firefox refuses it; load it for the session from `about:debugging` → This Firefox → Load Temporary Add-on.
3. Click the extension's toolbar button: it should say **Connected**.

If you added a test version of the extension by hand before, remove it first.

## What it does

- **Fast downloads** in up to 64 sections at once, that pause, continue, and survive restarts. Expired links can be refreshed and carry on where they stopped.
- **Takes over browser downloads**, and adds **Download with LDM** to the right-click menu. Downloads start straight away in their own small window, like IDM, while the app stays in the tray; a "Download complete" window offers Open and Show in folder.
- **Video button** on any page: YouTube, X, Instagram (posts with several videos, and reels), Facebook, TikTok and more, with a choice of quality or audio only.
- **Torrents** from magnet links and .torrent files, with protection that keeps your IP behind your VPN or proxy.
- **Tidy folders** for each type of file (Video, Music, Documents, Compressed, Programs, Torrents, General), with file types you can edit.
- **Duplicate links** are caught; **queues** and schedules; a speed limit.
- **Pauses when the internet goes away**, without losing anything.
- **Light, dark or same as Windows**.
- **Light in the background**: in the tray the app frees its window's memory, and torrent support only runs while torrents do.

Layó's Download Manager for Windows: a free download manager that splits each file into many sections, catches downloads from your browser, grabs videos from web pages, and downloads torrents privately.

*Developed by [Layó](https://layothedeveloper.com)*

## Download

| File | What it is |
| --- | --- |
| `LayosDownloadManager_0.2.0_x64-setup.exe` | The installer (Windows 10 and 11, 64-bit) |
| `layos-download-manager-chromium-0.2.0.zip` | Browser extension for Chrome, Edge, Brave, Opera and Vivaldi |
| `layos-download-manager-firefox-0.2.0.zip` | Browser extension for Firefox |
| `layos-download-manager-chromium-store-0.2.0.zip` | For store submission only (not for installing by hand) |

## Install

1. Run `LayosDownloadManager_0.2.0_x64-setup.exe`. It installs for your user account, with no admin rights needed. Windows may say "Windows protected your PC" because the installer isn't code-signed yet: click **More info → Run anyway**. It installs over 0.1.0.
2. **Chrome, Edge, Brave, Opera, Vivaldi:** unzip the chromium zip into a folder you'll keep. Open the browser's extensions page, turn on **Developer mode**, click **Load unpacked** and choose that folder. (If you loaded 0.1.0, remove it first.)
3. **Firefox:** open `about:debugging#/runtime/this-firefox`, click **Load Temporary Add-on…** and choose the Firefox zip. Firefox removes it when it closes, until the extension is signed.
4. Click the extension's toolbar button: it should say **Connected**, or **Ready** when the app isn't running yet (it starts by itself when a download comes in).

## What's new in 0.2.0

- **Works from the tray, like IDM.** Browser downloads start at once with their own small window (progress, speed, time left, Pause); the main window stays in the tray. "Ask before downloading" asks in that same small window while the file already downloads. A "Download complete" window opens when it's done, and the mini window (also in the tray menu) shows everything in progress.
- **Pauses when the internet goes away**, keeping what it has; nothing restarts until you continue it.
- **Folders for each type of file** (Video, Music, Documents, Compressed, Programs, Torrents, General), created when missing, each changeable, and **editable file types** (which extensions go where).
- **"Download with LDM"** in the browser's right-click menu, on links and images; videos streamed in pieces go through the video grabber.
- **Duplicate links** are caught: open or continue the one you have, or download it again.
- **Expired links** can be refreshed and continue from where they stopped.
- **The video button** works on Facebook, X, Instagram, Reddit and other feeds, under overlays and in embedded players.
- **The list:** a Type column, 14 columns to choose from, sorting, resizing and reordering; a side bar and details panel that fold and resize; tooltips on every icon; dialogs and menus that scroll at any window size.
- **Exit** closes the app (the window's close button keeps it in the tray).

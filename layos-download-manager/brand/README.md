# Brand

Layó's Download Manager uses the branding of [layothedeveloper.com](https://layothedeveloper.com), Layó's portfolio site.

| | Light | Dark |
| --- | --- | --- |
| Accent (cobalt) | `#2866ee` | `#57a8ff` |
| Accent hover | `#1b47d3` | `#78c6ff` |
| Text | `#111a2f` | `#edf2f8` |
| Background | `#f7fafe` | `#080e1b` |
| Lime spark | `#bef050` | `#bef050` |

All tokens are in [tokens.css](tokens.css).

- **Font:** Archivo (variable), in `fonts/`, under the SIL Open Font License (`fonts/OFL.txt`).
- **Layó's mark and wordmark:** `layo-mark-*.svg` and `layo-wordmark-*.svg`, in a light-background and a dark-background version. Used in the "Developed by Layó" credit, which links to layothedeveloper.com.
- **Product icon:** a cobalt tile with a download arrow over a bar cut into sections; the section still downloading is lime. It's drawn by `../extension/tools/make-icons.py`.

Design rules carried over from the site: no solid left-border accent stripes, and no decorative status dots. Status is shown with tinted, outlined labels instead.
